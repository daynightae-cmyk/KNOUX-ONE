## CURRENT LIMITATION
Current path compares archive manifests without extracting content; ZIP uses a Windows/.NET compression route and 7z/RAR depend on external 7-Zip listing. The external-tool dependency and format/parser coverage keep this partial.

## TARGET COMPLETE BEHAVIOR
Archive comparison without unsafe extraction, with normalized manifest entries, nested limits, encrypted-archive reporting, anti-bomb metadata limits, and clear distinction between exact archive bytes vs equivalent contained manifests.

## TECHNICAL GAP / RECOMMENDED IMPLEMENTATION
Use native ZIP parser in Rust for ZIP where practical; normalize path separators/case policy carefully without losing original names; hash manifest tuple (normalized path, uncompressed size, CRC/hash if available). For 7z/RAR either require an explicitly detected 7-Zip binary with version/license evidence or adopt a vetted library per format. Never extract merely to compare.
