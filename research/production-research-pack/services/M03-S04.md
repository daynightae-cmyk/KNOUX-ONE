## CURRENT LIMITATION
Current code resolves ffprobe/ffmpeg from PATH, probes metadata, decodes only the first 120 seconds at 1 frame/10s, 32x32 grayscale, then hashes the entire sampled stream. This is real evidence but prefix-limited and brittle to trims, offsets, frame-rate/transcode changes, or same-intro/different-content videos.

## TARGET COMPLETE BEHAVIOR
Near-duplicate video detection resilient to common transcodes and modest trims, with metadata + multi-segment perceptual frame signatures, optional audio correlation, transparent confidence, and explicit dependency diagnostics.

## TECHNICAL GAP / RECOMMENDED IMPLEMENTATION
Sample across the timeline (e.g. normalized temporal positions) rather than only the prefix; build per-frame perceptual hashes and compare sequences with bounded alignment tolerance; combine duration ratio, dimensions, codec-independent frame signatures and optional audio fingerprint. Exact BLAKE3 remains a separate exact proof, not a similarity proof. Resolve/bundle FFmpeg only under a documented licensing strategy.
