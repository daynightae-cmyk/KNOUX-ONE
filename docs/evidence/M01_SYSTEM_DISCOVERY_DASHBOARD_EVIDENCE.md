# دليل تنفيذ M01-S01 ولوحة التحكم

**التاريخ:** 19 أغسطس 2026
**النطاق:** تحسين حقيقة مسار **M01-S01 — اكتشاف الجهاز** وتخصيص لوحة التحكم لعرض الأدلة المقاسة فقط.
**خارج النطاق:** لا يتناول هذا الدليل توقيع Authenticode، ولا ينفذ أو يرفع حالة أي خدمة من الخدمات المتبقية، ولا يثبت تحقق واجهة Tauri end-to-end.

## سلسلة التنفيذ الفعلية

| الطبقة         | التنفيذ المثبت                                                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| إجراء المستخدم | زر **فحص هذا الجهاز** في [`DashboardView.tsx`](../../src/components/views/DashboardView.tsx).                                                                 |
| منسق الواجهة   | `runSmartScan` في [`KnouxContext.tsx`](../../src/context/KnouxContext.tsx).                                                                                   |
| عقد TypeScript | [`systemDiscoveryMapper.ts`](../../src/services/systemDiscoveryMapper.ts) لا يمرر إلا قيماً صالحة ومقاسة إلى `SystemSpecs`.                                   |
| الجسر المقيد   | `NativeClient.executeCapability('m01_s01', 'm01.system.discover')` ثم allowlist في [`nativeCommandRegistry.ts`](../../src/services/nativeCommandRegistry.ts). |
| أمر Tauri      | `m01_system_discover_complete` مسجل في [`main.rs`](../../src-tauri/src/main.rs).                                                                              |
| تنفيذ Windows  | PowerShell غير تفاعلي يقرأ CIM وWindows Defender وFirewall وSecure Boot وTPM.                                                                                 |
| النتيجة        | هوية الجهاز، المعالج، الذاكرة المتاحة والإجمالية، الأقراص المنطقية، وحقول الحماية الاختيارية مع وقت القياس ومصدر الأدلة.                                      |

لا تستخدم الواجهة اسم مستخدم ثابتاً أو عنوان IP تجريبياً أو حالة Defender/Firewall افتراضية. تبقى القيم غير التي لم تقاس فارغة أو `null`؛ ولا تحول إلى "آمنة" أو "غير آمنة" بلا دليل من Windows.

## ما تغير فعلياً

وسّع التنفيذ الأصلي عقد `SystemDiscoveryData` بأقراص منطقية قابلة للقياس وبحالتي Defender وFirewall الاختياريتين. وصحح عقد JSON الخاص بحقلَي RAM إلى `totalRamGB` و`availableRamGB`، لأن عدم اتساق تسمية `GB` كان يسقط قيم ذاكرة مقاسة أثناء deserialization. كما أصبح اسم الجهاز يأتي من `Win32_ComputerSystem.Name` أولاً بدلاً من الاعتماد الحصري على متغير بيئة قد لا يكون موجوداً.

يحوّل `systemDiscoveryMapper` هذه الأدلة إلى نموذج الواجهة بعد تحقق نوعي ورقمي. لا يحسب الذاكرة المستخدمة أو نسبتها إلا إذا كان مجموع الذاكرة والذاكرة المتاحة مقاسين وبعلاقة صالحة. ولا يحسب التخزين إلا من أحجام ومساحات حرة منطقية صالحة. أما وقت التشغيل فيحسب من وقت إقلاع Windows المقاس فقط.

| العنصر                                     | الحالة الصادقة بعد هذه الدفعة                                                   |

## الدفعة التالية المقترحة

تستهدف الدفعة التالية التناقض الصريح في `KnouxContext`: أزرار التنظيف القديمة تسجل أن M02 مخطط، بينما الكتالوج ومعالجات Rust يملكان مساراً مقيداً. لن تُفعل هذه الأزرار إلا بعد ربطها بطلب فحص حقيقي ثم preview وموافقة وتنفيذ ونتيجة متحققة واختبار Windows مستقل.
